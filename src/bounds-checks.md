# การตรวจสอบขอบเขต

โดยค่าเริ่มต้น การเข้าถึงชนิดข้อมูลคอนเทนเนอร์อย่างสไลซ์และเวกเตอร์ใน Rust จะมีการตรวจสอบขอบเขต (bounds check) ซึ่งอาจส่งผลต่อประสิทธิภาพ เช่นภายในลูปฮอต แม้จะไม่บ่อยอย่างที่คุณอาจคาดคิดก็ตาม

มีหลายวิธีที่ปลอดภัยในการแก้ไขโค้ด เพื่อให้คอมไพเลอร์ทราบความยาวของคอนเทนเนอร์และสามารถขจัดการตรวจสอบขอบเขตออกไปได้ด้วยการเพิ่มประสิทธิภาพ

- แทนที่การเข้าถึงองค์ประกอบโดยตรงในลูปด้วยการวนซ้ำผ่านอิเทอเรเตอร์
- แทนที่จะเข้าถึง `Vec` ด้วยดัชนีภายในลูป ให้สร้างสไลซ์ของ `Vec` ก่อนลูป แล้วเข้าถึงสไลซ์ด้วยดัชนีภายในลูป
- เพิ่มแอสเซอร์ชันเกี่ยวกับช่วงของตัวแปรดัชนี
[**ตัวอย่างที่ 1**](https://github.com/rust-random/rand/pull/960/commits/de9dfdd86851032d942eb583d8d438e06085867b),
[**ตัวอย่างที่ 2**](https://github.com/image-rs/jpeg-decoder/pull/167/files).

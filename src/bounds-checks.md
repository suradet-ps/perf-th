# การตรวจสอบขอบเขต

โดยค่าเริ่มต้น การเข้าถึงข้อมูลในชนิดข้อมูลประเภทคอนเทนเนอร์ เช่น สไลซ์ (slice) และเวกเตอร์ (`Vec`) ในภาษา Rust จะมีการตรวจสอบขอบเขต (bounds checks) อยู่เสมอ ซึ่งอาจส่งผลกระทบต่อประสิทธิภาพได้ เช่น เมื่อเกิดขึ้นภายในลูปที่ทำงานบ่อย (hot loop) แม้ว่าจะเกิดขึ้นไม่บ่อยเท่าที่คุณคิดก็ตาม

มีเทคนิคที่ปลอดภัย (safe) หลายวิธีในการปรับแก้โค้ด เพื่อให้คอมไพเลอร์ทราบขนาดความยาวของคอนเทนเนอร์ล่วงหน้า และสามารถออปติไมซ์เพื่อตัดการตรวจสอบขอบเขตออกไปได้:

- เปลี่ยนจากการเข้าถึงสมาชิกโดยตรงด้วยดัชนี (indexing) ภายในลูปมาเป็นการวนซ้ำผ่านอิเทอเรเตอร์ (iteration)
- แทนที่จะเข้าถึงสมาชิกของ `Vec` ด้วยดัชนีภายในลูป ให้สร้างสไลซ์ของ `Vec` ขึ้นมาก่อนเข้าลูป แล้วจึงเข้าถึงสมาชิกของสไลซ์นั้นด้วยดัชนีภายในลูปแทน
- ใส่ assertion (เช่น `assert!`) เพื่อการันตีช่วงของตัวแปรดัชนี

[**ตัวอย่างที่ 2**](https://github.com/image-rs/jpeg-decoder/pull/167/files).

การปรับโค้ดเพื่อให้คอมไพเลอร์ละเว้นการตรวจสอบขอบเขตอาจมีความซับซ้อนและต้องอาศัยชั้นเชิง เอกสาร [Bounds Check Cookbook] มีคำอธิบายและรายละเอียดเพิ่มเติมเกี่ยวกับหัวข้อนี้

[Bounds Check Cookbook]: https://github.com/Shnatsel/bounds-check-cookbook/

และหากจำเป็นจริง ๆ ยังมีทางเลือกสุดท้ายคือการใช้เมธอดที่ไม่ปลอดภัย (`unsafe`) อย่าง [`get_unchecked`] และ [`get_unchecked_mut`]

[`get_unchecked`]: https://doc.rust-lang.org/std/primitive.slice.html#method.get_unchecked
[`get_unchecked_mut`]: https://doc.rust-lang.org/std/primitive.slice.html#method.get_unchecked_mut

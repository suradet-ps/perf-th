# บทนำ

ประสิทธิภาพ (performance) เป็นสิ่งสำคัญสำหรับโปรแกรม Rust จำนวนมาก

หนังสือเล่มนี้รวบรวมเทคนิคที่ช่วยปรับปรุงคุณลักษณะด้านประสิทธิภาพของโปรแกรม Rust เช่น ความเร็วในการทำงาน การใช้หน่วยความจำ และขนาดไบนารี (binary size) นอกจากนี้ หัวข้อ [เวลาในการคอมไพล์] ยังรวบรวมเทคนิคที่ช่วยลดเวลาในการคอมไพล์ของโปรแกรม Rust ด้วย เทคนิคบางอย่างใช้เพียงการเปลี่ยนการตั้งค่าการบิลด์ แต่มีอีกหลายเทคนิคที่ต้องแก้ไขโค้ด

[เวลาในการคอมไพล์]: compile-times.md

เทคนิคบางอย่างเป็นเรื่องเฉพาะของ Rust ทั้งหมด และบางอย่างเป็นแนวคิดที่นำไปใช้กับโปรแกรมที่เขียนด้วยภาษาอื่นได้ (มักต้องดัดแปลงเล็กน้อย) หัวข้อ [เคล็ดลับทั่วไป] ยังรวมหลักการทั่วไปที่ใช้ได้กับทุกภาษาโปรแกรม อย่างไรก็ตาม หนังสือเล่มนี้เน้นเรื่องประสิทธิภาพของโปรแกรม Rust เป็นหลัก และไม่สามารถใช้แทนคู่มือทั่วไปเกี่ยวกับการโปรไฟล์และการเพิ่มประสิทธิภาพได้

[เคล็ดลับทั่วไป]: general-tips.md

หนังสือเล่มนี้ยังเน้นเทคนิคที่ใช้ได้จริงและผ่านการพิสูจน์แล้ว โดยหลายเทคนิคมีลิงก์ไปยัง pull request หรือแหล่งข้อมูลอื่นที่แสดงให้เห็นว่ามีการนำเทคนิคนั้นไปใช้กับโปรแกรม Rust จริงอย่างไร เนื้อหาสะท้อนภูมิหลังของผู้เขียนหลัก ซึ่งค่อนข้างเอนเอียงไปทางการพัฒนาคอมไพเลอร์และออกห่างจากสาขาอื่นๆ เช่น การคำนวณเชิงวิทยาศาสตร์

หนังสือเล่มนี้ตั้งใจเขียนให้กระชับ เน้นความกว้างมากกว่าความลึก เพื่อให้อ่านได้อย่างรวดเร็ว และจะลิงก์ไปยังแหล่งข้อมูลภายนอกที่ให้รายละเอียดลึกกว่าเมื่อเหมาะสม

หนังสือเล่มนี้มุ่งเป้าไปที่ผู้ใช้ Rust ระดับกลางและระดับสูง ผู้ใช้ Rust มือใหม่มีสิ่งที่ต้องเรียนรู้อีกมากมาย และเทคนิคในเล่มนี้อาจกลายเป็นสิ่งรบกวนที่ไม่เกิดประโยชน์สำหรับพวกเขา

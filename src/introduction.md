# บทนำ

ประสิทธิภาพ (performance) เป็นหัวใจสำคัญของโปรแกรม Rust จำนวนมาก

หนังสือเล่มนี้รวบรวมเทคนิคต่างๆ ที่ช่วยยกระดับคุณลักษณะด้านประสิทธิภาพของโปรแกรม Rust ไม่ว่าจะเป็นความเร็วในการประมวลผล การใช้หน่วยความจำ และขนาดไฟล์ไบนารี (binary size) นอกจากนี้ ในหัวข้อ [เวลาในการคอมไพล์] ยังมีเทคนิคที่ช่วยลดเวลาในการคอมไพล์โปรแกรม Rust อีกด้วย โดยเทคนิคบางอย่างทำได้ง่ายๆ เพียงแค่ปรับเปลี่ยนการตั้งค่าการบิลด์ (build configuration) ในขณะที่อีกหลายเทคนิคจำเป็นต้องแก้ไขโค้ด

[เวลาในการคอมไพล์]: compile-times.md

เทคนิคบางอย่างเป็นเรื่องเฉพาะของภาษา Rust โดยตรง ในขณะที่บางอย่างเป็นแนวคิดที่นำไปประยุกต์ใช้กับภาษาโปรแกรมอื่นๆ ได้ (ซึ่งมักต้องปรับแก้ให้เหมาะสม) บท [เคล็ดลับทั่วไป] ยังได้รวบรวมหลักการทั่วไปที่นำไปใช้ได้กับทุกภาษาโปรแกรมไว้ด้วย ถึงกระนั้น หนังสือเล่มนี้เน้นเรื่องประสิทธิภาพของโปรแกรมภาษา Rust เป็นหลัก จึงไม่สามารถใช้ทดแทนคู่มือฉบับสมบูรณ์ทั่วไปเกี่ยวกับการทำ profiling และ optimization ได้

[เคล็ดลับทั่วไป]: general-tips.md

หนังสือเล่มนี้ยังให้ความสำคัญกับเทคนิคที่นำไปใช้ได้จริงและผ่านการพิสูจน์มาแล้ว โดยหลายเทคนิคจะมีลิงก์ไปยัง pull request หรือแหล่งอ้างอิงอื่น ซึ่งแสดงตัวอย่างการนำเทคนิคดังกล่าวไปใช้งานจริงในโปรแกรม Rust โลกความเป็นจริง ทั้งนี้ เนื้อหาจะสะท้อนถึงภูมิหลังของผู้เขียนหลัก โดยจะเอนเอียงไปทางการพัฒนาคอมไพเลอร์เป็นหลัก และไม่ได้เน้นสาขาอื่นๆ เช่น การคำนวณเชิงวิทยาศาสตร์ (scientific computing)

หนังสือเล่มนี้ตั้งใจเขียนให้กระชับ เน้นความครอบคลุมในแนวกว้างมากกว่าการเจาะลึกเฉพาะจุด เพื่อให้คุณอ่านจบได้อย่างรวดเร็ว และจะใส่ลิงก์ไปยังแหล่งข้อมูลภายนอกสำหรับผู้ที่ต้องการศึกษาในเชิงลึกเมื่อเหมาะสม

หนังสือเล่มนี้เหมาะสำหรับผู้ใช้ Rust ในระดับกลางไปจนถึงระดับสูง สำหรับผู้เริ่มต้นภาษา Rust ยังมีพื้นฐานอีกมากที่ต้องทำความเข้าใจ เทคนิคในเล่มนี้จึงอาจกลายเป็นเรื่องที่ทำให้เสียสมาธิหรือหลงทางโดยไม่จำเป็น

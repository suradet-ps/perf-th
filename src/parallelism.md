# การประมวลผลแบบขนาน

Rust มีการรองรับการเขียนโปรแกรมแบบขนานที่ปลอดภัยได้อย่างยอดเยี่ยม ซึ่งนำไปสู่การปรับปรุงประสิทธิภาพครั้งใหญ่ได้ มีหลายวิธีในการนำการประมวลผลแบบขนานเข้ามาในโปรแกรม และวิธีที่ดีที่สุดสำหรับแต่ละโปรแกรมจะขึ้นอยู่กับการออกแบบของมันอย่างมาก

อย่างไรก็ตาม การอธิบายการประมวลผลแบบขนานอย่างลึกซึ้งนั้นอยู่นอกขอบเขตของหนังสือเล่มนี้

หากคุณสนใจการประมวลผลแบบขนานด้วยเธรด เอกสารของเครต [`rayon`] และ [`crossbeam`] เป็นจุดเริ่มต้นที่ดี [Rust Atomics and Locks][Atomics] ก็เป็นแหล่งข้อมูลที่ยอดเยี่ยมเช่นกัน

[`rayon`]: https://crates.io/crates/rayon
[`crossbeam`]: https://crates.io/crates/crossbeam
[Atomics]: https://marabos.nl/atomics/

หากคุณสนใจการประมวลผลแบบขนานของข้อมูลระดับละเอียด [บทความบล็อกนี้][blog post] เป็นภาพรวมที่ดีของสถานะการรองรับ SIMD ใน Rust ณ เดือนพฤศจิกายน 2025

[blog post]: https://shnatsel.medium.com/the-state-of-simd-in-rust-in-2025-32c263e5f53d

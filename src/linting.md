# การใช้ลินต์

[Clippy] คือชุดของ lint (กฎการตรวจสอบโค้ด) สำหรับดักจับข้อผิดพลาดที่พบบ่อยในโค้ด Rust ถือเป็นเครื่องมือชั้นยอดสำหรับการตรวจโค้ด Rust ทั่วไป และยังมีประโยชน์อย่างมากต่อการปรับปรุงประสิทธิภาพ เพราะมี lint หลายตัวที่คอยตรวจหารูปแบบโค้ดที่ทำให้โปรแกรมทำงานได้ช้ากว่าที่ควร

เนื่องจากการตรวจจับปัญหาโดยอัตโนมัติย่อมดีกว่าการไล่หาด้วยตนเอง เนื้อหาในส่วนที่เหลือของหนังสือเล่มนี้จึงจะไม่กล่าวถึงปัญหาด้านประสิทธิภาพที่ Clippy ตรวจจับได้อยู่แล้วโดยค่าเริ่มต้น

## พื้นฐาน

[Clippy]: https://github.com/rust-lang/rust-clippy

เมื่อติดตั้งแล้ว ก็สามารถเรียกใช้งานได้อย่างง่ายดายด้วยคำสั่ง:
```text
cargo clippy
```
คุณสามารถดูรายการ lint ด้านประสิทธิภาพทั้งหมดได้ที่ [รายการลินต์] แล้วกดยกเลิกการเลือกกลุ่ม lint ทั้งหมด ยกเว้นกลุ่ม "Perf"

[รายการลินต์]: https://rust-lang.github.io/rust-clippy/master/

นอกจากจะช่วยให้โค้ดทำงานเร็วขึ้นแล้ว คำแนะนำจาก lint ด้านประสิทธิภาพมักจะช่วยให้โค้ดเรียบง่ายขึ้นและเป็นสำนวนภาษาที่เหมาะสม (idiomatic) มากขึ้นด้วย จึงคุ้มค่าที่จะปฏิบัติตาม แม้กับโค้ดส่วนที่ไม่ได้ถูกเรียกใช้งานบ่อยก็ตาม

ในทางกลับกัน คำแนะนำจาก lint บางข้อที่ไม่ได้จัดอยู่ในกลุ่มประสิทธิภาพโดยตรง ก็อาจช่วยเพิ่มประสิทธิภาพได้เช่นกัน ตัวอย่างเช่น lint ด้านรูปแบบการเขียนโค้ด [`ptr_arg`] แนะนำให้เปลี่ยนพารามิเตอร์ที่เป็นคอนเทนเนอร์ชนิดต่างๆ ให้เป็น slice เช่น เปลี่ยนจาก `&mut Vec<T>` เป็น `&mut [T]` ซึ่งแม้เป้าหมายหลักของคำแนะนำนี้คือเพื่อให้ได้ API ที่ยืดหยุ่นกว่าเดิม แต่ก็มักส่งผลให้โค้ดทำงานเร็วขึ้นด้วย เนื่องจากช่วยลดการอ้างอิงหลายชั้น (indirection) และเปิดโอกาสให้คอมไพเลอร์ optimize โค้ดได้ดียิ่งขึ้น
[**ตัวอย่าง**](https://github.com/fschutt/fastblur/pull/3/files)

[`ptr_arg`]: https://rust-lang.github.io/rust-clippy/master/index.html#ptr_arg

## การห้ามใช้ชนิดข้อมูล

ในบทถัดๆ ไป เราจะเห็นว่าในบางสถานการณ์ การหลีกเลี่ยงชนิดข้อมูลบางอย่างใน Standard Library แล้วหันไปใช้ตัวเลือกอื่นที่ทำงานได้เร็วกว่าถือเป็นสิ่งที่คุ้มค่า แต่หากคุณตัดสินใจเปลี่ยนไปใช้ตัวเลือกเหล่านั้น ก็อาจเผลอเรียกใช้ชนิดข้อมูลจาก Standard Library ในบางจุดโดยไม่ได้ตั้งใจได้ง่าย

คุณสามารถใช้ lint [`disallowed_types`] ของ Clippy เพื่อป้องกันปัญหานี้ได้ ตัวอย่างเช่น หากต้องการสั่งห้ามไม่ให้ใช้ hash table จาก Standard Library (ด้วยเหตุผลที่จะอธิบายในหัวข้อ [การแฮช]) ให้เพิ่มไฟล์ `clippy.toml` ลงในโปรเจกต์ของคุณ พร้อมระบุข้อความดังต่อไปนี้:
```toml
disallowed-types = ["std::collections::HashMap", "std::collections::HashSet"]
```

[การแฮช]: hashing.md
[`disallowed_types`]: https://rust-lang.github.io/rust-clippy/master/index.html#disallowed_types

# การใช้ลินต์

[Clippy] คือชุดลินต์สำหรับจับข้อผิดพลาดที่พบบ่อยในโค้ด Rust เป็นเครื่องมือที่ยอดเยี่ยมสำหรับรันกับโค้ด Rust โดยทั่วไป และยังช่วยด้านประสิทธิภาพได้ด้วย เพราะลินต์จำนวนหนึ่งเกี่ยวข้องกับรูปแบบโค้ดที่อาจทำให้ประสิทธิภาพต่ำกว่าที่ควร

เนื่องจากการตรวจจับปัญหาโดยอัตโนมัติเป็นสิ่งที่พึงปรารถนามากกว่าการตรวจจับด้วยมือ ส่วนที่เหลือของหนังสือเล่มนี้จะไม่กล่าวถึงปัญหาด้านประสิทธิภาพที่ Clippy ตรวจจับได้อยู่แล้วโดยค่าเริ่มต้น

## พื้นฐาน

[Clippy]: https://github.com/rust-lang/rust-clippy

เมื่อติดตั้งแล้ว ก็รันได้ง่ายๆ ด้วยคำสั่ง:
```text
cargo clippy
```
รายการลินต์ด้านประสิทธิภาพทั้งหมดดูได้โดยไปที่[รายการลินต์] แล้วยกเลิกการเลือกกลุ่มลินต์ทั้งหมด ยกเว้นกลุ่ม "Perf"

[รายการลินต์]: https://rust-lang.github.io/rust-clippy/master/

นอกจากทำให้โค้ดเร็วขึ้นแล้ว คำแนะนำจากลินต์ด้านประสิทธิภาพมักทำให้โค้ดเรียบง่ายและเป็นสำนวนที่เหมาะสมมากขึ้นด้วย จึงคุ้มค่าที่จะทำตาม แม้กับโค้ดที่ไม่ได้ถูกเรียกใช้บ่อยนัก

ในทางกลับกัน คำแนะนำจากลินต์ที่ไม่เกี่ยวกับประสิทธิภาพบางข้อก็ช่วยเพิ่มประสิทธิภาพได้ ตัวอย่างเช่น ลินต์ด้านสไตล์ [`ptr_arg`] แนะนำให้เปลี่ยนอาร์กิวเมนต์ที่เป็นคอนเทนเนอร์ชนิดต่างๆ ให้เป็นสไลซ์ เช่น เปลี่ยนอาร์กิวเมนต์ `&mut Vec<T>` เป็น `&mut [T]` แรงจูงใจหลักของข้อนี้คือ สไลซ์ให้ API ที่ยืดหยุ่นกว่า แต่ก็อาจทำให้โค้ดเร็วขึ้นด้วย เนื่องจากการอ้อมลดลงและคอมไพเลอร์มีโอกาสเพิ่มประสิทธิภาพได้ดีขึ้น
[**ตัวอย่าง**](https://github.com/fschutt/fastblur/pull/3/files).

[`ptr_arg`]: https://rust-lang.github.io/rust-clippy/master/index.html#ptr_arg

## การห้ามใช้ชนิดข้อมูล

ในบทถัดไป เราจะเห็นว่าบางครั้งควรหลีกเลี่ยงชนิดข้อมูลบางอย่างในไลบรารีมาตรฐาน แล้วหันไปใช้ทางเลือกที่เร็วกว่า หากคุณตัดสินใจใช้ทางเลือกเหล่านี้ ก็เป็นเรื่องง่ายที่จะเผลอใช้ชนิดข้อมูลในไลบรารีมาตรฐานในบางจุดโดยไม่ตั้งใจ

คุณสามารถใช้ลินต์ [`disallowed_types`] ของ Clippy เพื่อหลีกเลี่ยงปัญหานี้ได้ ตัวอย่างเช่น หากต้องการห้ามใช้ตารางแฮชของไลบรารีมาตรฐาน (ด้วยเหตุผลที่อธิบายไว้ในหัวข้อ[การแฮช]) ให้เพิ่มไฟล์ `clippy.toml` ลงในโค้ดของคุณโดยมีบรรทัดต่อไปนี้
```toml
disallowed-types = ["std::collections::HashMap", "std::collections::HashSet"]
```

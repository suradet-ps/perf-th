# โค้ดเครื่อง

เมื่อคุณมีโค้ดฮอตชิ้นเล็กๆ การตรวจสอบโค้ดเครื่องที่ถูกสร้างขึ้นว่ามีความไม่มีประสิทธิภาพใดๆ เช่น[การตรวจสอบขอบเขต] ที่ขจัดออกได้หรือไม่ ก็อาจคุ้มค่า เว็บไซต์ [Compiler Explorer] เป็นแหล่งข้อมูลที่ยอดเยี่ยมเมื่อทำสิ่งนี้กับโค้ดชิ้นเล็กๆ ส่วน [`cargo-show-asm`] เป็นเครื่องมือทางเลือกที่ใช้กับโปรเจกต์ Rust เต็มรูปแบบได้

[การตรวจสอบขอบเขต]: bounds-checks.md
[Compiler Explorer]: https://godbolt.org/
[`cargo-show-asm`]: https://github.com/pacak/cargo-show-asm

ในทำนองเดียวกัน โมดูล [`core::arch`] ให้เข้าถึงอินทรินสิก (intrinsic) เฉพาะสถาปัตยกรรม ซึ่งหลายตัวเกี่ยวข้องกับคำสั่ง SIMD

[`core::arch`]: https://doc.rust-lang.org/core/arch/index.html

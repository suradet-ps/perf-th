# โค้ดเครื่อง

เมื่อคุณมีโค้ดสั้น ๆ ในส่วนที่มีการประมวลผลบ่อยมาก (very hot code) อาจคุ้มค่าที่จะลองตรวจสอบโค้ดเครื่อง (machine code / assembly) ที่คอมไพเลอร์สร้างขึ้น เพื่อดูว่ามีจุดใดที่ไร้ประสิทธิภาพหรือไม่ เช่น มี[การตรวจสอบขอบเขต]ที่สามารถขจัดออกไปได้หรือไม่ ทั้งนี้ เว็บไซต์ [Compiler Explorer] เป็นแหล่งข้อมูลชั้นยอดสำหรับการตรวจสอบโค้ดเครื่องกับตัวอย่างโค้ดสั้น ๆ ในขณะที่ [`cargo-show-asm`] ก็เป็นอีกหนึ่งเครื่องมือทางเลือกที่สามารถนำไปใช้ตรวจสอบโค้ดเครื่องกับโปรเจกต์ Rust ขนาดเต็มได้

[การตรวจสอบขอบเขต]: bounds-checks.md
[Compiler Explorer]: https://godbolt.org/
[`cargo-show-asm`]: https://github.com/pacak/cargo-show-asm

นอกจากนี้ โมดูล [`core::arch`] ยังเปิดให้เข้าถึงฟังก์ชันอินทรินซิก (intrinsics) เฉพาะของแต่ละสถาปัตยกรรมฮาร์ดแวร์ ซึ่งหลายตัวเกี่ยวข้องกับชุดคำสั่ง SIMD โดยตรง

[`core::arch`]: https://doc.rust-lang.org/core/arch/index.html
